## HugRemote v1.5.3

Bản phát hành sửa số liệu **Current Session / Context Window** theo đúng model Claude đang được sử dụng thực tế, thay vì suy đoán từ tên model hoặc mặc định 200k.

### Context Window theo native Claude CLI
- Lấy `model`, `totalTokens`, `rawMaxTokens`, `maxTokens` và `percentage` trực tiếp từ control request native `get_context_usage` với `detail: summary` của Claude CLI.
- Composer và popup Limits hiển thị đúng effective model cùng context window thực tế. Model 1M hiện hiển thị `1M`, không còn rơi về `200k` do label `sonnet`, `opus`, `haiku` hoặc custom alias.
- Xóa toàn bộ heuristic theo tên model và fallback context cố định trong Composer, Limits Popup và Session Hub.
- Khi native context chưa có dữ liệu, giao diện hiển thị trạng thái chưa xác định thay vì dựng số liệu giả.

### Tự phục hồi trạng thái “Chưa xác định”
- Theo dõi canonical Claude CLI session identity trong frontend context scope.
- Khi Claude tạo hoặc thay đổi `cliSessionId` sau lượt phản hồi, hydration tự vô hiệu hóa kết quả unavailable cũ và gọi lại context endpoint đúng một lần.
- Response thuộc CLI identity cũ không thể ghi đè kết quả mới, kể cả transport không tuân thủ AbortSignal.
- `cliSessionId` chỉ dùng làm freshness identity cục bộ và không được gửi từ trình duyệt lên context endpoint.

### Scope, race và an toàn tài nguyên
- Server và CWD của context probe phải khớp canonical app session; request chéo server/CWD bị từ chối trước khi khởi chạy CLI.
- Canonical `cliSessionId` chỉ được đọc từ server state. Input từ client không thể cung cấp resume ID.
- Coalesce probe trùng scope, cache LRU ngắn 2 giây và giới hạn tối đa 4 probe đồng thời.
- Cache key dùng JSON tuple, tránh va chạm xuyên session/target/model.
- Lỗi HTTP được phân loại bằng error class tin cậy và thông báo cố định; lỗi transport không làm lộ path hoặc chẩn đoán nội bộ.
- Cleanup tiến trình xử lý đúng SIGTERM/SIGKILL grace, close và EPIPE muộn.

### Ổn định giao diện và session
- Chặn PATCH response cũ ghi đè lựa chọn model/effort mới.
- Không giữ array index qua `await`; response của session đã xóa không thể sửa nhầm session khác.
- `/clear` vô hiệu hóa context cũ ngay lập tức và tải lại native context sau khi hoàn tất.
- Popup retry đúng một lần khi mở lại từ trạng thái unavailable/error.
- Session Hub chỉ hiển thị native context cho exact active scope; session chưa fetch hiển thị `— / —`.

### Bàn phím ảo Terminal dễ đọc hơn
- Tăng ký tự phím thường đúng 1,5 lần: desktop `12.5px → 18.75px`, mobile `11px → 16.5px`.
- Tăng tương ứng các phím chức năng, giữ nguyên chiều cao vùng bấm `34px` desktop và `31px` mobile.
- Thu gọn padding ngoài còn `3px`, gap ngoài `3px`, gap giữa hàng/phím `2px` để tận dụng chiều rộng màn hình.
- Dùng legend biểu tượng gọn cho Tab, Caps Lock, Enter, Shift, Escape, Control và Alt; mỗi phím vẫn có `aria-label` và `title` đầy đủ.
- Browser matrix `320/360/375/390/480px`: đủ 62 phím, không nhãn nào overflow và không thiếu accessible name.

### Phạm vi và giới hạn
- Bản phát hành này sửa context-window usage. Account quota 5 giờ/tuần vẫn là luồng dữ liệu riêng và chưa được chuyển sang native `get_usage`.
- Backend restart chưa có durable recovery cho process Claude đang chạy; hãy hoàn tất hoặc dừng task trước khi cập nhật.
- Updater caveat có sẵn: `--dry-run` có thể restart service ở nhánh đã là bản mới nhất. Không chạy updater trong lúc Claude đang generation.
