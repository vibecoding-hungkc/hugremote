# Feature Plan: Claude Session Name Sync, Workspace Running State, Multi-Repo Git (<=5 Levels) & Vietnamese Speech-to-Text Mic

## Summary
1. Ensure Claude session names set in HugRemote are passed to the Claude Code CLI (`--name`) when starting/resuming CLI sessions and kept synchronized across `SmartHeader.vue`, `ClaudeSessionHubModal.vue`, and `WorkspaceSidebar.vue`.
2. Expose real-time running state on Claude sessions in `WorkspaceSidebar.vue` (and `analysis/prototypes/prototype.html`) using ONLY the spinning loading indicator (`.dw-claude-running.status-indicator`) without a stop button on the Workspace row.
3. Discover and track nested Git repositories up to 5 directory levels deep (`0..5`) inside the active project across both `QuickWorkspacePanel.vue` (`#quick-pane-git`) and `GitView.vue`.
4. Add a Vietnamese Speech-to-Text Mic button (`#btn-claude-mic`) immediately next to the permission shield (`ri-shield-check-line`) in `ClaudeView.vue` (and `analysis/prototypes/prototype.html`) using the browser Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition` with `lang = 'vi-VN'`), displaying strictly 2 states (`recording` / `Đang thu` and `transcribing` / `Đang phân tích`) before filling the Claude input box and resetting to `idle`.

## Acceptance Criteria
- [x] **AC-1 (CLI `--name` & Metadata Persistence on Start/Update):** When `ClaudeService.streamClaudePrompt` spawns `claude` CLI, it passes `--name <session.name>` whenever `session.name` is non-empty (with automatic retry fallback if an older binary rejects `--name`), and persists `session.name` to the bound CLI session metadata (`.hugremote-meta.json` and `.jsonl` `custom-title`) when `cliSessionId` is bound or when `updateSession` / `renameProjectSession` renames a session (both local and remote SSH).
- [x] **AC-2 (Consistent Session Name in Drop Menu & Workspace):** `SmartHeader.vue`, `ClaudeSessionHubModal.vue` (both Web and CLI tabs), and `WorkspaceSidebar.vue` display the configured session name (`session.name`) without overwriting user-set or default `'chat'` / project names with the first/last user prompt text.
- [x] **AC-3 (Workspace Claude Session Running State — Spinner Only):** When a Claude session is working (`s.isRunning` or `claudeStore.isSessionRunning(s.id)` / `claudeStore.isGenerating`), its row in `WorkspaceSidebar.vue` (and `analysis/prototypes/prototype.html`) renders the `.running` state with a visible `.dw-claude-running.status-indicator` spinner and NO `.btn-dw-claude-stop` button, clearing immediately when the run finishes or is stopped.
- [ ] **AC-4 (Multi-Repo Git Discovery & Operations up to 5 Levels Deep):** `GitService.discoverRepos(rootPath, 5)` scans up to depth 5 (`0..5`, local and SSH) for Git repositories inside the active project, `GET /api/git/repos` returns the discovered repositories (`relPath`, `name`, `depth`, `branch`, `ahead`, `behind`, `changedCount`, `clean`), and `/api/git/*` routes (`status`, `diff`, `branches`, `checkout`, `pull`, `push`, `stage`, `unstage`, `commit`) scope operations to `repoPath` (validated strictly within `project.rootPath`, depth `<= 5`) so both `QuickWorkspacePanel.vue` and `GitView.vue` can filter (`all` / `dirty`), rescan (`Quét lại 5 cấp`), and manage any nested repository.
- [ ] **AC-5 (Web Speech API `vi-VN` Mic Button Next to `ri-shield-check-line` in Claude Chat):** `ClaudeView.vue` (and `analysis/prototypes/prototype.html`) renders `#btn-claude-mic.claude-mic-btn` immediately to the left of `.claude-permission-shield-btn` (`ri-shield-check-line`), uses browser Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition` with `lang = 'vi-VN'`), displays strictly 2 states (`recording` / `Đang thu` and `transcribing` / `Đang phân tích`, never a 3rd "đã điền" status), appends recognized text into `#claude-ext-textarea` / `.claude-ext-textarea`, and cleans up recognition buffers immediately.
